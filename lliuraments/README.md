# Agents del mode dificil

> Historial. El lliurament final és a [`../lliurament_final/`](../lliurament_final/).

`submission_hybrid16_fulltrain.zip` es el paquet que ha obtingut **23,63 punts oficials**, segons el resultat comunicat per l'equip. Es el millor agent actual conegut.

`agent_validat_prefinal.zip` conte els pesos anteriors al tall usats a la prova local; el seu score oficial no esta mesurat.

`informe_Riviera_Maya_Boys.pdf` i `../README_REPRODUCCIO.md` descriuen els experiments, les dades i les limitacions. L'informe es anterior al resultat oficial de 23,63.

Per treballar sobre l'agent de 23,63, descomprimiu el ZIP en un directori nou mantenint els seus fitxers auxiliars junts. `mode_dificil/` conte el prototip anterior de 23,11; el baseline de 23,45 es a `hard_work/original/`.
