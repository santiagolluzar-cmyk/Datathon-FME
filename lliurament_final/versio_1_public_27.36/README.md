# Versió 1 — solució oficial per al rànquing públic (27,36)

`submission.zip` és exactament el paquet enviat (SHA-256 `ff74a035809a2b7e…`). Obtingué **27,36 punts**
al rànquing públic del Mode Difícil (2n lloc; CO₂ −26,37 %, cost −29,65 %, 0 infraccions).

És l'agent v5 amb una sola regla afegida: l'últim dia de cada setmana de test planifica fins al final de la
setmana i dona valor a l'energia guardada (`BLOCK_END_VALUE`). Així arriba a la setmana següent amb la bateria
plena, i el rànquing públic és la primera meitat de cada setmana.
